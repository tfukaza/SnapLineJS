SnapSort is a drag-and-drop interface library for the web.
Its framework-neutral API and first-party Svelte and React bindings ship from
the single `@snap-engine/snapsort` package.
The goal of SnapSort is to provide _utilities_ for
making drag-and-drop, not pre-built components. This means:
  - You only need to know two components: `Item` and `Container`. Every UI is derived from these primitives.
  - Extensive hooks to customize features.
  - Wide array of configurations for drag and drop behavior, animations, etc.
  - Style-less by default, bring your own CSS.

> [!WARNING]
> SnapSort is in early beta. Expect breaking API changes, incomplete features, and behavioral instability between releases. It is not yet recommended for production-critical interfaces.
>
> SnapSort currently targets pointer-based interactions. Keyboard controls and other accessibility features have not been implemented yet.
