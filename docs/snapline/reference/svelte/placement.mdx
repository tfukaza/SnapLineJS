Pass a core `PlacementController<T>` to `Placement`. The component listens at
window scope while the controller is active and optionally renders
`preview(snapshot)`.

`cancelOnOutside`, `cancelOnSecondaryButton`, and `cancelOnEscape` default to
`true`. Creation and persistence belong in the controller’s `onCommit`
callback.
