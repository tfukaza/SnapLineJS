`NodeMirror` owns a node's position, selection, resize behavior, and
connectors. Construct it with `new NodeMirror(engine, parent, config)`, assign
its committed element, then call `remeasureDomGeometry()`.

`NodeConfig` accepts `id` (stable domain identity — minted when omitted;
supply it for persistence), `minWidth`, `minHeight`, `metadata`, `callbacks`,
and `edgePan`.

`NodeCallbacks` covers drag (`canStartDrag`, `resolveDragPosition`,
`onDragStart`, `onDrag`), selection (`resolveSelectionMode`,
`onSelectionChange`), resize (`onSizeChange`), lines
(`resolveNewLine`, `onLinesChanged`), and the batched `onGeometryCommit` used
for persistence. `resolveNewLine` seeds serializable payload onto a newly
dragged line; a connector-level callback may override it.

## Resize regions

Create a `ResizeRegionMirror(engine, node, handle)` for each application DOM
region, then assign its `element`. It is a normal `ElementObject` child of the
node. The DOM owns hover, cursor, placement, thickness, border interaction,
and visuals; SnapLine owns only the resize gesture and geometry.

| Export | Value |
| --- | --- |
| `RESIZE_HANDLES` | The eight handles `"n" \| "ne" \| "e" \| "se" \| "s" \| "sw" \| "w" \| "nw"` |

## Data attributes

Selection state is written to the element as `data-selected="true" | "false"`
and `data-snapline-state="focus" | "idle"` — style either without extra
callbacks. Adapters additionally stamp `data-snapline-type="node"`.

Enumerate nodes with `query(engine).nodes()`; look one
up by domain id with `query(engine).node(id)`.
