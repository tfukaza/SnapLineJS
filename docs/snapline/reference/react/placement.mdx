Pass a core `PlacementController<T>` to `Placement`. Supply `children` as a
render function when an active preview should be displayed.

The component forwards pointer movement, primary commit, secondary-button
cancel, outside cancel, and Escape cancel according to its boolean props.
Application state should create the actual node from the controller’s
`onCommit` event.
