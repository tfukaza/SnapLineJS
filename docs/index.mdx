Choose the part of SnapEngine that matches what you are building. Each project
has its own focused guides and API reference while sharing the same interaction
foundation.

## SnapEngine Core

Use [SnapEngine Core](/docs/snapengine/introduction) when authoring reusable
interaction tools or building advanced behavior directly from the engine's
input, layout, collision, camera, and animation systems.

## Assets

### SnapSort

[SnapSort](/docs/snapsort/introduction) is the best starting point for sortable
lists, kanban boards, and other drag-and-drop interfaces.

### SnapLine

SnapLine is a planned toolkit for node graphs, connectors, selection, groups,
and visual workflows that is coming soon.

### SnapZap

SnapZap is a focused zoom-and-pan toolkit that is coming soon.
