Use the framework selector to switch between equivalent Vanilla, Svelte, and
React pages.

SnapLine ships one package with framework bindings exposed as subpaths.

| Import path | Primary exports |
| --- | --- |
| `@snap-engine/snapline` | Node, connector, line, selection, group, placement, controlled-graph, and query core APIs |
| `@snap-engine/snapline/svelte` | `Node`, `Connector`, `Line`, `Select`, `Group`, `Placement`, `ControlledGraph` |
| `@snap-engine/snapline/react` | `Engine`, `Node`, `Connector`, `Line`, `Select`, `Group`, `Placement`, `ControlledGraph` |

The framework-neutral API has no per-module subpaths — import all core objects
from `@snap-engine/snapline`.
